# MovieBox Android App 0.1.4

Public version **0.1.4**, internal build **7**, package `org.emransm.moviebox.phone`.
The installed name remains **MovieBox**. This is a separate native client, not the Android patch.

This update refines portrait and fullscreen player controls, audio labels, the episode rail, Home Categories and title-specific recommendations. For you appends up to 50 valid unique results if the upstream service supplies them; it never invents missing titles.

Optional updates use a compact Update/Later prompt and an immediate checking state under Me. An explicit Update tap downloads privately inside MovieBox with progress and Cancel. The download must match release size, SHA-256, package, newer version and installed signer. Ready to install offers a separate Install action; Android still asks for confirmation. There is no automatic download, silent install or promised automatic restart. The new interface cannot change an older already-installed app retroactively.

Successful background metadata checks are spaced twelve hours apart. Failed checks persist a short cooldown; GitHub's Retry-After/rate-limit reset is respected, including manual checks. Cached verified availability can still be shown on the next cold launch without a new request during that cooldown. Later suppresses the current session, not every future launch. Turning off optional reminders remains supported.

# MovieBox Android App 0.1.1

This is a reliability update for the independently authored Android phone app.
The Android patch and Android TV applications are separate projects.

## Same-version logo refresh

The current APK is 0.1.1, version code 4. Logo artwork is transparent, the top-left mark is larger, and launcher foregrounds keep safe padding. Older Android icon variants were checked in source; actual older-device runtime remains unverified. Android launchers may supply their own background shape.

The original build 3 APK and its unchanged original-filename checksum are retained under clearly labelled previous-build assets so their download counters and provenance remain available. Use `MovieBox-Android-App-0.1.1.apk` and its matching checksum for the current build. [Original build validation](0.1.1-build3-validation.json).

The Git tag keeps the initial 0.1.1 source history. The current build source is the explicitly linked commit and `MovieBox-Android-App-0.1.1-source.zip` asset, rather than GitHub's automatic initial-tag source archive. Same-version reminders may not announce this visual refresh; manually install the current APK over the existing app.

## What changed

- Use transparent logo choices, a larger header mark and safe launcher-mask padding.
- Return to the browsing position you left, and keep reading when title details refresh.
- Clear search without old results unexpectedly coming back.
- Recover from failed sources and artwork with useful retry choices.
- Read controls more easily with larger text and clearer audio names.
- Back up your list and watch progress, preview a restore, and recover unreadable saved data.
- Download supported video files over Wi-Fi by default; allow mobile data only when you choose it.
- See clearer download failure reasons and retry with a fresh source when available.
- Keep subtitle storage bounded without removing the subtitle currently playing.
- See unfinished titles under Continue watching, while completed titles remain in History.
- Receive optional update reminders after playback, with clearer messages when a release is incomplete.

## Installing

File: `MovieBox-Android-App-0.1.1.apk`. Package: `org.emransm.moviebox.phone`.
Version code: 4. Minimum Android 6/API 23; target API 35.

Install over the existing native app to retain its private data. The existing
signing identity is retained. Do not uninstall to resolve a signature mismatch;
check that you downloaded this same project instead. You can make a library backup
under Me before updating. Updates are optional and never installed silently.

## Verification and limits

The exact 0.1.1 release APK passed 131 scoped scenarios in one Android 17 physical-phone run (174.119 seconds, zero failures), after an in-place update with the retained signer. 29 unit tests passed; lint reports zero errors and 89 warnings. App data and device settings were preserved; the temporary test package was removed. See [artifact validation](0.1.1-validation.json).

No universal compatibility or instant-loading promise is made. Current minimum-OS,
other-device, low-memory, RTL and full accessibility checks remain incomplete.
Some tests use controlled metadata, a fake download backend and generated captions;
they do not certify every remote stream, carrier, document provider or disk failure.
Segmented HLS/DASH offline downloads are not implemented. Source availability,
languages, qualities and captions depend on the external service.

Search pagination, process-death navigation restoration, richer resume context and
some whole-app usability improvements remain open. Optional captured-art fixtures
are not redistributed; related tests explicitly skip without their inputs.

This community app is not an official MovieBox release. Its source license does
not grant rights to third-party names, catalogue artwork or media.

# MovieBox Android App 0.1.2

Version code 5. Install over the existing native app to retain My list, history and preferences. This is separate from the Android patch.

- Open titles directly in a portrait watch page, with audio, quality, subtitles and episodes below the video.
- Search with recent queries and suggestions; return to your results after playback.
- Keep 18+ filtering on by default, with a Settings switch. Filtering depends on available service metadata and cannot guarantee that every title is classified.
- Use separate family-mode catalogue caches and retain classification metadata in backups.
- See a clear message when GitHub temporarily limits update checks. No silent downloads or forced installation.

## Checked scope

The signed APK passed 35 release unit tests, lint/build, 53 scoped Android 6/API 23 emulator scenarios, eight updater scenarios, and two baseline/update probes. The emulator in-place update from0.1.1 retained saved library and preferences. Many scenarios use controlled metadata/generated video rather than the live service. HQ reviewed source, evidence and corrected screenshots; the owner accepted the portrait layout preview.

This exact APK has not been installed on the maintainer's phone: the owner chose to test updating through the app after publication. Live hotfeed behavior, every remote stream, other phones and exact upstream UI/feature parity remain unverified. No universal compatibility or instant-loading guarantee.

The home/icon pictures currently in the README show the explicitly labelled historical0.1.1 physical-phone capture; they are not relabelled as0.1.2.

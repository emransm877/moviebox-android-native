# Security reports

Do not put credentials, private stream links, signing material, personal library
exports or account information in public issues. Use a private GitHub security
advisory if available; otherwise contact the maintainer at emransm877@gmail.com
with a minimal description first, without attaching secrets.

Download only from this project's release page and compare the supplied SHA256
checksum when needed. Android signatures protect update identity; they do not
prove third-party content rights or universal device safety. This native client
is separate from the patched upstream APK and uses no embedded project API token.

Security fixes are maintained on the current source/release line. Unsupported
external-service responses, expiring media links and unavailable content may
require a source fix; do not disable platform protections to work around them.
